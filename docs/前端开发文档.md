# 生物启扉协会官网 · 前端开发文档

> 站点:江西农业大学生物启扉协会(EcoRem)官网 —— 启迪生命,扉向未来。
> 线上地址:`https://bird-z.github.io/OLeaf/`
> 设计体系见根目录 [`design.md`](../design.md),令牌见 [`tokens.css`](../tokens.css)。

---

## 1. 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | React 19 + Vite 8 | JSX 为主,仅 shadcn 组件用 TSX |
| 样式 | Tailwind CSS 4(`@tailwindcss/vite`)+ 原生 CSS 文件 | 设计令牌经 `tokens.css` 注入 |
| 路由 | react-router-dom 7(**HashRouter**) | 规避 GitHub Pages 无 SPA 回退的 404 |
| 动效 | GSAP 3 · motion 12 · tw-animate-css | 编排式动效,尊重 reduced-motion |
| 组件 | @base-ui/react · shadcn · lucide-react | `cn()`(clsx + tailwind-merge)合并类名 |
| 内容 | react-markdown + remark-gfm | 文章页渲染 markdown |
| 演示数据 | json-server(`test.json`,端口 3001) | Mapp 资讯页演示 |
| 质量 | oxlint | 见 `.oxlintrc.json` |

## 2. 常用命令

```bash
pnpm dev        # 开发服务器
pnpm build      # 构建 → dist/
pnpm preview    # 预览构建产物
pnpm lint       # oxlint
pnpm server     # json-server 演示数据(localhost:3001)
```

## 4. 路由

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/#/` | Home | 整页翻屏五区块:Slogan → About → Studios → Members → Join(+ Footer) |
| `/#/science` | SciencePage | 科学与工程档案 |
| `/#/events` | EventsPage | 教育活动档案 |
| `/#/popular` | PopularPage | 知识普及(分类列表) |
| `/#/popular/:category/:title` | ArticlePage | markdown 文章渲染 |

注意:**API 中转站是独立服务(localhost:3000),Nav 直链,不经本站路由。**

## 5. 关键约定(踩坑记录)

1. **页内锚点必须走 JS 滚动。** HashRouter 下 `#/join` 会被当成 hash 路由导致白屏。
   一律用 `src/lib/scrollTo.js` 的 `useAnchorScroll()` / `scrollToId()`;
   跨页锚点先 `navigate('/')` 再滚动。
2. **样式只引用令牌。** `index.css` 的 `:root` 语义别名(`--text`、`--bg`、`--accent`…)
   全部指向 `tokens.css`;新组件不得内联色值 / 字体栈。
3. **行楷子集需同步。** 新增 display 文案(节标题、成员引文等)后,用 fontTools 合并
   `@fontsource/zhi-mang-xing` 分包并 `pyftsubset` 重新生成
   `src/assets/fonts/zhi-mang-xing-subset.woff2`。
4. **暗底为全局基调。** `color-scheme: dark`;亮底元素(弹层、卡片)需自行处理对比,
   暗底焦点环用 `--color-focus-on-dark`。
5. **动效降级。** 所有滚动 / 揭示动画检查 `prefers-reduced-motion`
   (参照 `scrollTo.js` 的 `reduceMotion()`)。
6. **图片资源带 base 前缀。** 引用 `public/` 资源时用 `import.meta.env.BASE_URL`
   或相对路径,部署在 `/OLeaf/` 子路径下。

## 6. 内容工作流(知识普及文章)

1. markdown 放入 `src/data/articles/<分类>/`
2. 运行 `node scripts/sync-articles.mjs` 重建 `articles.json` 索引
   (生成 excerpt 与阅读时长)
3. ArticlePage 通过 `/popular/:category/:title` 按索引加载并渲染

## 7. 部署(GitHub Pages)

1. `pnpm build` → `dist/`
2. `vite.config.js` 已设 `base: '/OLeaf/'`,资源路径自带子路径前缀
3. `dist/` 推送到 `gh-pages` 干净分支,Pages 源选该分支 `/(root)`
4. HashRouter 保证刷新 / 直达链接不 404
