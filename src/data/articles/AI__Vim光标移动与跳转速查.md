	
# Vim 光标移动与跳转速查

除了 `gd`（跳转到当前文件内的定义）之外，以下操作可以让你在代码中实现 **"手不离主键区"**，与 VS Code 原生快捷键（`F12`、`Alt + F12`）不冲突，可混合使用。

---

## 1. 符号/定义跳转

| 快捷键 | 作用 |
|--------|------|
| `gD` | 跳转到当前文件中该符号的**全局定义**（Global definition） |
| `Ctrl + ]` | 跳转到标签定义（Tag），常用于跨文件跳转（需配合 tags 文件） |

---

## 2. 精准字符跳转（极力推荐）

| 快捷键 | 作用 |
|--------|------|
| `f{char}` | 在当前行，**向前**查找并跳转到指定字符上（如 `fa` 跳到下一个 `a`） |
| `F{char}` | 在当前行，**向后**查找并跳转到指定字符上 |
| `;` | 继续向相同方向找下一个匹配项 |
| `,` | 反向查找上一个匹配项（与 `;` 方向相反） |

> **📌 插件增强**：配合 VS Code 的 EasyMotion 插件，可使用 `<Leader><Leader>f{char}` 实现屏幕内任意位置的快速跳跃。

---

## 3. 括号与结构块匹配

| 快捷键 | 作用 |
|--------|------|
| `%` | 在括号 `()`、`[]`、`{}` 之间快速跳转，适合检查嵌套层级或寻找闭合括号 |
| `[[` | 向上跳转到类、函数或段落级别 |
| `]]` | 向下跳转到类、函数或段落级别 |

> 对 Python、C++ 等语言特别有用。

---

## 4. 文本对象操作（Vim 的灵魂）

不需要手动选中，直接通过组合键对特定结构进行操作：

| 快捷键   | 作用               | 记忆方式                           |
| ----- | ---------------- | ------------------------------ |
| `diw` | 删除光标所在的整个单词      | **d**elete **i**nner **w**ord  |
| `ci"` | 修改双引号内的内容        | **c**hange **i**nner `"`       |
| `da(` | 删除整个圆括号及其内容      | **d**elete **a**round `(`      |
| `diB` | 删除花括号 `{}` 内部的内容 | **d**elete **i**nner **B**lock |

### 通用模式

```
{操作}{范围}{目标}
```

- **操作**：`d`（删除）、`c`（修改）、`y`（复制）、`v`（选择）
- **范围**：`i`（inner，不含边界）、`a`（around，包含边界）s (，匹配边界)
- **目标**：`w`（单词）、`"`/`'`（引号内）、`(`/`[`/`{`（括号内）、`t`（标签）、`p`（段落）

---

## 5. 历史记录与位置记忆

| 快捷键 | 作用 |
|--------|------|
| `Ctrl + o` | 跳转到**上一个**光标所在位置（older） |
| `Ctrl + i` | 跳转到**下一个**光标所在位置（newer） |
| `` ` `` `` `" `` | 返回上次编辑的位置 |
| `m{a-z}` | 在当前位置打标记（如 `ma`、`mb`） |
| `` ` `` `a` | 瞬间跳回到标记 `a` 的位置 |

---

## 6. 行内快速定位

| 快捷键 | 作用 |
|--------|------|
| `0` | 移动到当前行的**绝对行首** |
| `^` | 移动到当前行的**第一个非空字符处** |
| `$` | 移动到当前行的**行尾** |

---

## 总结速查表

```
gd          → 跳转到局部定义
gD          → 跳转到全局定义
Ctrl + ]    → 跳转到标签定义

f{char}     → 行内向前找字符
F{char}     → 行内向后找字符
;           → 重复上次 f/F 查找（同方向）
,           → 重复上次 f/F 查找（反方向）

%           → 匹配括号跳转
[[ / ]]     → 函数/类级别上下跳转

diw         → 删除单词
ci"         → 修改引号内内容
da(         → 删除括号及内容
diB         → 删除花括号内内容

Ctrl + o/i  → 历史光标位置前后跳转
m{a-z}      → 打标记
`{a-z}      → 跳到标记：：

0 / ^ / $   → 行首/首非空字符/行尾
```
