# grep

grep（全称 Global Regular Expression Print）是 Linux 和 Unix 系统中最核心、最常用的文本搜索工具。它的核心作用是在一个或多个文件中，按照你指定的“模式”（可以是普通字符串，也可以是复杂的正则表达式）查找内容，并把匹配到的行打印出来。

无论是日常写代码、查服务器日志，还是过滤数据，grep 都是必备的实用技能。以下是它的核心用法速览：

### 🛠️ 基础语法

```bash
grep [选项] "搜索模式" 文件名
```

### ⭐ 最常用的实战选项

1. **忽略大小写 (`-i`)**  
    匹配时会忽略英文大小写，比如同时匹配 error、Error 和 ERROR。
    
    ```bash
    grep -i "error" log.txt
    ```
    
2. **显示行号 (`-n`)**  
    在输出结果前加上行号，方便快速定位到文件的具体位置。
    
    ```bash
    grep -n "root" /etc/passwd
    ```
    
3. **统计匹配行数 (`-c`)**  
    不显示具体内容，只输出匹配了多少行，非常适合做数据统计。
    
    ```bash
    grep -c "failed" log.txt
    ```
    
4. **反向匹配/排除 (`-v`)**  
    显示**不包含**指定内容的行。常用于过滤掉配置文件中的注释行（比如以 `#` 开头的行）。
    
    ```bash
    grep -v "#" config.conf
    ```
    
5. **精确匹配整个单词 (`-w`)**  
    只匹配完整的单词。比如搜索 `user`，不会匹配到 `user1` 或 `username`。
    
    ```bash
    grep -w "user" file.txt
    ```
    
6. **递归搜索目录 (`-r`)**  
    在当前目录及其所有子目录的文件中进行搜索，找代码或配置时非常有用。
    
    ```bash
    grep -r "TODO" ./
    ```
    
7. **显示上下文 (`-A / -B / -C`)**  
    查看匹配行周围的内容，排查日志报错时特别好用。
    - `-A 2`：显示匹配行及**后** 2 行
    - `-B 2`：显示匹配行及**前** 2 行
    - `-C 2`：显示匹配行及**前后各** 2 行

### 🔗 配合管道符 (`|`) 使用

grep 经常与其他命令配合使用，用来过滤其他命令的输出结果。

- **查找特定进程**：`ps aux | grep "nginx"`（只看和 nginx 相关的进程）
- **查找特定端口的连接**：`netstat -tuln | grep ":80"`

### 🔡 结合正则表达式[[正则表达]]

grep 支持强大的正则表达式，可以实现更复杂的匹配：

- **匹配行首 (`^`)**：`grep "^root" file.txt`（只匹配以 root 开头的行）
- **匹配行尾 (`$`)**：`grep "bash$" /etc/passwd`（只匹配以 bash 结尾的行）
- **匹配任意字符 (`.`)**：`grep "s.n" file.txt`（可以匹配 sun, son, s7n 等）
- **匹配字符集 (`[]`)**：`grep "[0-9]" file.txt`（匹配包含任意数字的行）
