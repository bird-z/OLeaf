
这是一份为你整理的 Linux x86_64 汇编代码速查笔记。在 GDB 调试中，默认使用的是 **AT&T 语法**（寄存器带 `%`，立即数带 `$`，目标操作数在右边）。掌握这些基础指令，能让你在看 TUI 汇编窗口或排查底层 Bug 时事半功倍。

### 数据传送与栈操作

- **`mov src, dest`**：数据传送（赋值）。例如 `mov %eax, %ebx` 表示把 `eax` 的值赋给 `ebx`。
- **`lea src, dest`**：加载有效地址（常用于指针运算或高效加法）。例如 `lea 0x8(%rax), %rbx` 相当于 `rbx = rax + 8`。
- **`push src`**：将数据压入栈顶（栈指针 `rsp` 减小）。
- **`pop dest`**：从栈顶弹出数据到目标位置（栈指针 `rsp` 增大）。

### 算术与逻辑运算

- **`add src, dest`**：加法。`dest = dest + src`。
- **`sub src, dest`**：减法。`dest = dest - src`。
- **`inc dest`** / **`dec dest`**：自增 1 / 自减 1。
- **`imul src, dest`**：有符号乘法。
- **`idiv src`**：有符号除法（被除数默认在 `rax` 中，结果商在 `rax`，余数在 `rdx`）。
- **`and` / `or` / `xor`**：按位与、或、异或运算（`xor %rax, %rax` 常用来快速将寄存器清零）。
- **`not` / `neg`**：按位取反 / 求补码（取负）。

### 比较与条件跳转

- **`cmp src, dest`**：比较大小（本质是 `dest - src`，不保存结果，只改变标志寄存器）。
- **`test src, dest`**：逻辑测试（本质是 `dest & src`，常用于判断寄存器是否为 0）。
- **`jmp label`**：无条件跳转到指定标签（类似 C 语言的 `goto`）。
- **条件跳转**（通常紧跟在 `cmp` 或 `test` 之后）：
    - `je label` / `jz label`：相等 / 结果为 0 则跳转。
    - `jne label` / `jnz label`：不相等 / 结果不为 0 则跳转。
    - `jg label` / `jl label`：有符号数 大于 / 小于 则跳转。
    - `ja label` / `jb label`：无符号数 大于 / 小于 则跳转。

### 函数调用与系统调用

- **`call func`**：调用函数。自动将下一条指令的地址（返回地址）压栈，然后跳转到目标函数。
- **`ret`**：函数返回。从栈顶弹出返回地址并跳转回去。
- **`syscall`**：发起系统调用（如 `fork`、`read`、`write` 等底层操作，调用号通常放在 `rax` 中）。
- **`nop`**：空操作（不执行任何动作，常用于内存对齐或代码占位）。

### ️ 函数栈帧管理

- **`push %rbp`**：保存上一个函数的栈底指针。
- **`mov %rsp, %rbp`**：建立当前函数的栈底（栈帧初始化）。
- **`sub $0x20, %rsp`**：为当前函数的局部变量开辟栈空间（例如开辟 32 字节）。
- **`pop %rbp`**：恢复上一个函数的栈底指针（栈帧销毁）。

### GDB 汇编调试速查

- **`disassemble 函数名`**（简写 `disas`）：反汇编指定函数的全部汇编代码。
- **`x/i $pc`**：查看程序计数器（PC）当前指向的**下一条**即将执行的汇编指令。
- **`stepi`**（简写 `si`）：单步执行**一条**汇编指令（遇到 `call` 会钻进去）。
- **`nexti`**（简写 `ni`）：单步执行**一条**汇编指令（遇到 `call` 会直接跳过）。
- **`info registers`**：打印所有通用寄存器的当前值。
- **`set disassembly-flavor intel`**：如果你不习惯 AT&T 语法，可以切换成更常见的 Intel 语法（源操作数在左，目标在右，不带 `%`）。
